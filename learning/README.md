# 项目驱动学习路径

每阶段按“问题 → 原理 → 最小实验 → 观察 → 解释与局限”记录。

## P01：单轴仿真

学习任务：明确简化模型与单位；输入阶跃目标，保存误差、控制量、超调和稳定时间。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

## P02：执行器台架

学习任务：确认型号、驱动、电源、反馈、限位与急停；独立测试，不接视觉。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

## P03：视觉闭环

学习任务：接模拟或视觉目标，验证延迟、噪声、丢帧、目标丢失和恢复。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

## P04：双轴扩展

学习任务：完成轴向、坐标变换和标定；记录轴间影响，禁止直接复用单轴参数。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

## P05：控制研究

学习任务：固定轨迹，对比延迟补偿、滤波和控制策略；ROS 2 仅在系统集成需要时引入。

笔记需解释本阶段输入、输出、失败条件及为何采用当前方法。

资料按当前任务补充，不先堆积整套课程。
