# 设计与模块

## 目标

从单轴软件仿真开始，逐步建立带位置反馈的视觉跟随云台，再评估双轴拓展。

数据路径：目标观测 → 时效与置信度检查 → 目标误差 → 控制器 → 限幅/限位 → 执行器 → 位置反馈

| 模块 | 责任 |
| --- | --- |
| observation | 目标位置、帧尺寸、采集时间及新鲜度；记录接收时间 |
| controller | 误差到速度/位置指令；采样周期、死区、饱和及积分限制 |
| actuator | 驱动适配、位置反馈、限位和停止 |
| behavior | IDLE / TRACK / LOST / STOP；启动禁用，目标失效进入停止策略 |

## 接口初稿

观测输入候选：target_id、frame_id、image_size、bbox、confidence、capture_time、receive_time。不同节点时钟不能直接相减；先使用本地接收超时。图像像素误差不能未经标定直接当机械角度。控制输出必须声明单位和有效期。

以上是设计约定，不代表已有可互通实现。冻结接口时增加样例、边界条件和版本迁移说明。

## 范围

不重新训练通用视觉模型，不从无刷电机直接跳到整机；不在执行器、驱动、反馈和限位未知时上电。
