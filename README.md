# Robotic-Gaze · 主动视觉云台

如何把视觉误差变成稳定、受限且可恢复的机械运动？

从单轴软件仿真开始，逐步建立带位置反馈的视觉跟随云台，再评估双轴拓展。

## 独特性

不重新训练通用视觉模型，不从无刷电机直接跳到整机；不在执行器、驱动、反馈和限位未知时上电。

本库保存设计、学习过程和后续实现；不通过复制整套历史文件伪造完整工程。实验完成后才更新状态。
